BILYARD CLUB Android APK loyihasi — V2

Bu Android uchun Kivy asosida moslashtirilgan versiya. Asl Tkinter .py faylini Android bevosita ishlata olmaydi.

Asosiy imkoniyatlar:
- 5 bilyard + 3 tennis stoli
- soniya hisoblagichi, pauza/davom ettirish
- stolni tugatish va jami hisobni chiqarish
- menyudan mahsulot qo'shish
- kunlik stol/mahsulot tushumi hisoboti
- stol narxlarini o'zgartirish
- klub nomi, kirish va admin paroli sozlamalari
- mahsulot qo'shish

Hali ko'chirilmagan asl funksiyalar:
- mahsulot rasmlari va fon rasmini tanlash
- mahsulotlarni tahrirlash/o'chirish va tannarxni to'liq boshqarish
- haftalik/oylik batafsil hisobot
- avtomatik PDF hisobotni emailga yuborish
- eski Tkinter bazasini avtomatik ko'chirish

APK olish:
1. GitHub'da yangi repository yarating.
2. Arxivdagi fayllarni ochib, ichidagi fayllarni repository rootiga yuklang.
3. Actions -> Build Android APK -> Run workflow.
4. Yashil tugagach, Artifacts -> BILYARD-CLUB-APK ni yuklang.
5. ZIPni ochib .apk ni telefonda oching. Zarur bo'lsa Android Settings'da brauzer/Files uchun Install unknown apps ruxsatini yoqing.

Ma'lumotlar telefon ilovasining ichki xotirasida saqlanadi. APK hali qurilmagan; GitHub Actions'da build muvaffaqiyatli tugashi kerak.
